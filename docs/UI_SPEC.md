# UI_SPEC.md — UI / UX および画面設計仕様書

`docs/MASTER_SPEC.md` (#41〜#56) に基づく画面設計・カラーパレット・レスポンシブ要件を定義する。

---

## 1. デザインコンセプト・カラーパレット

- **基本方針**: 青基調でシンプルかつ洗練されたデザイン。大学業務システムとして信頼感があり、PC・スマートフォンの双方で直感的に使えること。
- **最重要UX原則**:
  - **学生**: 情報量を増やしすぎず、「今どの段階か」「次に何をいつまでにすべきか」が一目でわかること。
  - **管理者**: 全学生を漫然と並べるのではなく、「今フォロー・対応が必要な学生（期限超過・期限接近・目標未設定・長期未更新）」を最上部に表示すること。
  - **アクセシビリティ**: 色だけで状態を表現せず、必ず「アイコン＋テキストラベル」を併用する。

### カラー定義
| 用途 | カラー名 | HEXコード | Tailwind 目安 |
| :--- | :--- | :--- | :--- |
| プライマリ濃色（ヘッダー・サイドナビ等） | Navy | `#0B1F3A` | `bg-[#0B1F3A]` / `text-[#0B1F3A]` |
| プライマリアクセント（主要ボタン・強調） | Blue | `#2563EB` | `bg-blue-600` (`#2563EB`) |
| ベース背景 | Pale blue-gray | `#F8FAFC` / `#F1F5F9` | `bg-slate-50` / `bg-slate-100` |
| カード背景 | White | `#FFFFFF` | `bg-white` |
| 状態：成功・完了 | Green | `#16A34A` | `text-green-700 bg-green-50 border-green-200` |
| 状態：注意・まもなく・本日 | Orange | `#D97706` / `#EA580C` | `text-amber-700 bg-amber-50 border-amber-200` |
| 状態：危険・期限超過 | Red | `#DC2626` | `text-red-700 bg-red-50 border-red-200` |

## 3. 各画面仕様

### 3.1 ログイン画面 (`/login`)
- **表示要素**:
  - タイトル：「大学院研究進捗管理」
  - メールアドレス入力欄
  - パスワード入力欄
  - 「ログイン」ボタン
  - 案内文：「パスワードを忘れた場合は管理者へお問い合わせください」
- **非表示要素**: 新規登録リンク、OTP入力、Googleログインボタン等は一切置かない。

### 3.2 初回パスワード変更画面 (`/change-password`)
- `userProfile.mustChangePassword === true` の場合、他の全画面へのアクセスをブロックして本画面を表示。
- 新しいパスワード（8文字以上・確認入力つき）を設定し、Firebase Auth のパスワード更新および `mustChangePassword = false` 更新が完了したら本来のホーム画面へ遷移する。

### 3.3 兼務ユーザー用画面切替バー
- `roles.student === true && roles.admin === true` のユーザーのみ、ヘッダー右上に **「学生画面 ⇄ 管理者画面」** の切替トグルを表示する（再ログイン不要）。
- 一般学生（`admin !== true`）には切替UIを一切表示しない。

### 3.4 学生ホーム画面 (`/student`)
1. **期限超過アラートバナー**（期限超過タスクが1件以上ある場合のみ最上部に赤枠＋警告アイコンで強調表示）
2. **サマリーヒーローカード**:
   - **現在の研究進捗率**: 現在学年（M1またはM2）の `progressManaged = true` タスク完了率（プログレスバー＋完了件数/対象件数）
   - **今の段階**: 現在進行中（`IN_PROGRESS`）または直近取り組むべき研究フェーズ
   - **次にやること（1件強調）**: 最優先タスクのタイトル・学生アクション・期限日・残り日数
3. **直近予定リスト（3〜5件）**: 期限が近い未完了タスク
4. **カテゴリ別進捗**: カテゴリごとの完了/全体件数をコンパクトなバーで表示

### 3.5 学生進捗一覧・更新画面 (`/student/progress`)
- **学年タブ**: 現在学年（例: M2）をデフォルト表示し、過去学年履歴（M1）も閲覧可能。
- **フィルタ**: `すべて` / `未完了` / `進行中` / `期限接近` / `期限超過` / `完了`
- **編集機能**:
  - 状態変更（`未着手` / `進行中` / `完了` / `保留`）
    - ※ `完了` へ変更時は完了日を自動記録。`完了` から別状態へ戻す際は確認ダイアログ（「完了状態を解除し、完了日をクリアしますか？」）を表示。
  - 個人目標日（日付ピッカー、設定時は共通期限より優先適用される旨を明示）
  - コメント入力

### 3.6 管理者ダッシュボード (`/admin`)
**問題のある学生・今フォローが必要な学生を最優先で上部に配置する。**
1. **要対応KPIカード（クリックで該当学生フィルタへ連動）**:
   - **期限超過のある学生**（赤・危険アイコン）
   - **7日以内に期限が到来する学生**（オレンジ・注意アイコン）
   - **個人目標日が未設定の学生**（M1等で直近タスクに個人目標日がない学生）
   - **長期間更新なしの学生**（最終更新から一定日数以上経過）
2. **要フォロー学生クイックリスト**: 上記に該当する学生の氏名・学年・理由・超過/残日数・詳細リンク
3. **学年別平均進捗率（M1 / M2）**
4. **次の公式イベント（年度設定から直近イベントを表示）**

### 3.7 管理者：学生一覧・検索 (`/admin/students`)
- **表示項目**: 氏名、学年、進捗率、次の期限、期限超過数、最終更新日、指導教員
- **フィルタ**: 学年（M1/M2）、指導教員、在籍状態（在籍/休学/修了/退学）、期限状態
- **検索**: 氏名、`studentId`、メールアドレス
- **アクション**: 「新規学生登録」モーダル起動

### 3.8 管理者：学生詳細・管理 (`/admin/students/:studentId`)
- 学生プロフィール編集・学年進級処理（M1→M2進級時はM1履歴を残したままM2進捗を生成）
- 現在学年進捗および過去学年（M1）履歴の確認・管理者による状態/個人目標日/コメント編集
- アカウント管理：
  - パスワードリセット（新しい仮パスワードを設定 → `mustChangePassword = true` に自動設定）
  - アカウント利用停止 / 再有効化（修了・退学時も履歴を保持しAuth削除はしない）
  - 兼務ロール（`student` + `admin`）設定

### 3.9 管理者：年度設定 (`/admin/academic-years`) & ロードマップ管理 (`/admin/roadmap`)
- 年度別の公式イベント日程（日付・時刻・リマインド日数・Google Calendar表示有無）の編集と共通期限の再計算・Calendar同期トリガー
- 修士ロードマップ61件（M1: 17件、M2: 44件）の確認・ガイドラインやリマインド設定の調整
